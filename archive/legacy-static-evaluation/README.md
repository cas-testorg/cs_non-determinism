# Legacy Static Evaluation

> **Archived:** This material represents an earlier nondeterminism evaluation approach and is preserved for historical reference only.

The archived work explored a baseline-versus-CoreStory-assisted static investigation model using prompt suites, analysis rules, automation, validation notes, and token-metering experiments.

This is **not** the current proposed ND workflow. The active project now focuses on integrating runtime evidence, workflow routing, application context, engineering investigation, SME validation, and runtime confirmation.

Archived material may still be useful for understanding prior defect categories, prompt experiments, automation mechanics, or measurement attempts, but conclusions from this work should not be presented as current workflow claims without revalidation.
