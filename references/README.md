# Reference Material

This directory contains implementation and design references used while developing the ND workflow.

Reference material is not automatically customer-facing. It may summarize or point to authoritative CoreStory playbooks, taxonomies, or other engineering artifacts that evolve independently of this repository.

Before sharing an extract externally:

- Prefer the active documents under `docs/`.
- Verify that terminology still matches the authoritative source.
- Remove internal implementation detail that is not necessary to explain the workflow.
- Do not present reference snapshots as product commitments or final workflow behavior.
