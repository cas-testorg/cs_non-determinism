# Documentation

The active `docs/` tree contains the current ND workflow design and discovery material.

## Sharing Guidance

Documents under `docs/architecture/` and selected material under `docs/discovery/` are written so they can be extracted or adapted for customer discussions. They should remain factual, avoid unvalidated performance claims, and clearly distinguish proposed design from observed behavior.

Material under `references/` is implementation/reference context for this project and should not be assumed customer-facing without review.

Historical experiments are stored under `archive/legacy-static-evaluation/` and are not part of the current recommended workflow.

## Active Documents

- `architecture/nd-workflow-concept.md` — conceptual workflow and design boundaries.
- `architecture/nd-workflow-presentation.mmd` — presentation-oriented Mermaid source.
- `discovery/customer-workflow-inputs.md` — evidence and discovery inputs needed to validate the workflow.
