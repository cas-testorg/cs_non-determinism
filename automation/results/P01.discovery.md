## Safe / Mitigated Patterns
- The `msDRClimits` exemplar in `mscts/msutil/msUtil.cc` / `mscts/msutil/msUtil.h` looks intentionally safe in the sites I inspected: constructor state is sentinel-based, and the public `hasMax*()` helpers plus consumers like `isLenOk()` consistently gate use with `nwmathFloat::isInit()`.
- The `SMS_*_UNINIT` pattern in `mscts/mssc/msscXformProblem.cc` appears intentionally modeled as optional state. The constructor seeds `_optimizationType` / `_latencyType` with `UNINIT`, and setters/getters assert that callers must initialize before use. That is suspicious-looking, but I did not find a local source path here that established an invalid read.
