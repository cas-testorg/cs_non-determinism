# TC-002 Results

Store measured artifacts for the Synopsys-controlled comparison here.

Recommended layout:

```text
results/
├── arm-a-standalone/
└── arm-b-corestory-v3/
```

Each arm should retain the prompt, timestamps, model/version, source revision/view, skill version, rule version where applicable, runtime/token telemetry, tool/MCP call summaries, final report, candidate/qualification artifacts, and any anomalies or human interventions.

Do not store credentials, tokens, OAuth secrets, or other authentication material in this repository.
